KeyCrate

Gestor de contraseñas local y cifrado, sencillo y seguro.

Descargar desde GitHub

Protege tus credenciales localmente

KeyCrate cifra tus entradas con Fernet y guarda los datos en SQLite. Pensado para usuarios que prefieren control total sobre sus contraseñas sin depender de servicios externos.

Almacenamiento cifrado

Cifrado simétrico con Fernet para mantener tus contraseñas seguras en disco.

Gestión práctica

Listar, buscar, generar y copiar contraseñas con una interfaz clara.

Ligero y portátil

Funcionamiento local con una pequeña base SQLite y sin dependencias remotas.

Fácil de usar

Interfaz basada en `customtkinter` pensada para usuarios no técnicos.

Cómo probarlo

  1. Haz clic en "Descargar desde GitHub" o copia la URL.
  2. Clona el repositorio: git clone https://github.com/TheUniverse606/KeyCrate2.0.git
  3. Sigue el README del proyecto para crear el entorno y ejecutar main.py.
