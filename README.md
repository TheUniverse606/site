# KeyCrate — Página promocional local

Esta carpeta contiene un sitio estático simple para promocionar KeyCrate. Está aislada de la aplicación principal y no modifica nada en el proyecto original.

Contenido:
- `index.html` — página principal.
- `styles.css` — estilos.
- `script.js` — comportamiento del botón "Copiar URL".

Uso local rápido:

1. Abre `index.html` en tu navegador (doble clic en Windows).
2. Haz clic en "Descargar desde GitHub" para ir al repositorio oficial:

   https://github.com/TheUniverse606/KeyCrate2.0

3. (Opcional) Copia la URL del repo usando el botón "Copiar URL del repositorio".

Nota: Este sitio es estático y pensado para uso local o despliegue en hosting estático (GitHub Pages, Netlify, etc.).
